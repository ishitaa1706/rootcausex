# RootCauseX

AI-native runtime investigation platform for production anomaly analysis.

## Overview

RootCauseX helps engineers investigate production issues using AI-powered runtime reasoning.

The platform correlates:
- runtime metrics
- deployments
- git commits
- dependency relationships
- behavioral drift

Then uses AI to explain probable causes behind production anomalies.

This repository contains the hackathon MVP implementation.

## Core Idea

Traditional AI coding assistants understand source code but lack runtime production context.

RootCauseX adds:
- runtime awareness
- anomaly correlation
- deployment context
- dependency intelligence
- conversational investigation

The goal is to make AI feel like it understands production systems.
